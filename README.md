# Machine Learning Studies 

This repository is a systematic collection of machine learning experiments, algorithms, and data preprocessing techniques developed using **Google Colab**. It serves as a comprehensive roadmap from foundational regression to advanced ensemble methods and NLP.

## Repository Structure

The projects are organized by topic to reflect the learning trajectory:

*   **01-07: Regression Fundamentals**
    *   Simple & Multiple Linear Regression
    *   Regularization (Ridge Regression)
    *   Error Metrics Analysis (MSE, MAE, MAPE)
*   **08-11: Classification & Tree-Based Models**
    *   Logistic Regression
    *   Decision Trees & Random Forest
    *   Ensemble Learning & Hyperparameter Tuning
*   **12-14: Data Engineering & Preprocessing**
    *   Feature Scaling (Standard & MinMaxScaler)
    *   Categorical Encoding (Label & One-Hot Encoding)
*   **15: Specialized Projects**
    *   Natural Language Processing (NLP) Basics
    *   Customer Churn Prediction (End-to-End Case Study)     
*   **16: Time Series Forecasting**
    *   Financial Data Fetching (yfinance API)
    *   Time Series Prediction with Facebook Prophet
 
*   **17-18: Model Validation & Advanced Boosting**
    *   Airlines Booking Baggage Prediction (Cross-Validation)
    *   Hospital Readmission Risk Prediction (CatBoost Classifier)
    *   Handling Categorical Features & Multi-Class Problems
 
## Tech Stack

*   **Language:** Python
*   **Libraries:** Scikit-learn, Pandas, NumPy, Matplotlib, Seaborn, FBProphet, CatBoost 
*   **Environment:** Google Colab / Kaggle

## How to Use
Each folder contains a `.ipynb` notebook. You can open these files directly in Google Colab using the badge at the top of each notebook to reproduce the results.
